How this website is published

Steps to upload the site to a web server and open it in a browser.

1. Prepare the website

  • Keep all pages in one folder with index.html as the home page.
  • Store styles in css/, scripts in js/ and pictures in images/.
  • Use relative paths (e.g. images/logo.png) so links work on any server.
  • Test every page and link in Chrome, Edge and on a mobile screen.

2. Option A – Free hosting with GitHub Pages

  1. Create a free account on github.com and a new public repository.
  2. Upload the website files (or push them using Git): 
    git init
git add .
git commit -m "Publish Electrofly website"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
  3. Open the repository → Settings → Pages.
  4. Under Source, choose Deploy from a branch, select main and folder / (root), then Save.
  5. After 1–2 minutes the site is live at https://<username>.github.io/<repo>/.

3. Option B – Paid web hosting (cPanel)

  1. Buy a domain name (e.g. electroflytechstudio.in) and a hosting plan.
  2. Point the domain's DNS to the hosting server (name servers or A record).
  3. Log in to cPanel → File Manager → open public_html.
  4. Upload all files (or a ZIP and extract it), or use an FTP client such as FileZilla with the host, username and password from the hosting company.
  5. Enable SSL (HTTPS) from cPanel so the site is secure.

4. Access the website

  • Open any browser and type the URL, e.g. https://electroflytechstudio.in.
  • The browser sends a request to the web server, which returns index.html, CSS, JS and images.
  • Check the site on desktop and mobile, then share the link.
